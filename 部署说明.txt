升本英语教练 · 手机版部署说明
==============================

这个文件夹里有 5 个文件：
  index.html            整个应用（含 3646 个单词，约 600 KB）
  manifest.webmanifest  安装到桌面的配置
  sw.js                 离线缓存
  icon-192.png          图标
  icon-512.png          图标

一、电脑上先看效果
  直接双击 index.html，用 Chrome / Edge 打开即可。

二、手机上使用（推荐，能装到桌面）
  手机浏览器要求 HTTPS，所以需要先放到一个静态网站空间。最简单的两种：

  A. GitHub Pages（免费）
     1. 登录 github.com，新建仓库，例如 english-coach，设为 Public。
     2. 把这 5 个文件上传到仓库根目录。
     3. Settings → Pages → Source 选 "Deploy from a branch"，
        Branch 选 main、目录选 /(root)，保存。
     4. 等 1-2 分钟，访问 https://你的用户名.github.io/english-coach/
     5. 手机 Chrome 打开后，菜单里选「添加到主屏幕」。iPhone 用 Safari 的「共享 → 添加到主屏幕」。

  B. 任意支持 HTTPS 的静态托管（Netlify Drop、Cloudflare Pages、Vercel 等）
     把整个文件夹拖进去即可，不需要构建命令。

三、注意
  - 口语录音需要麦克风权限，浏览器会弹窗，选「允许」。
  - 学习记录保存在手机浏览器本地（localStorage），换浏览器或清缓存会丢失。
  - 电脑插件版和手机版的数据不互通。
  - 口语评分是「录音回放 + 自评」，不会上传任何录音。
